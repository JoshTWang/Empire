## Public vs. Private

- Public repos are accessible to everyone on the internet.
  - Anyone can see and clone the repo
- Private repos are only accessible to the owner and people who have been granted access.

## README.md

A README file is used to communicate important information about a repository including:

- What the project does
- How to run the project
- Who maintains the project

If you put a README.md in the root of your project, Github will recognize it and automatically display it on the repo's home page.

[Markdown cheatsheet](https://www.markdownguide.org/cheat-sheet/)



## Github Gists

Github Gists are a simple way to share code snippets and useful fragments with others.

Gists are much easier to create, but offer far fewer features than a typical Github Repository.

## Github Pages

Github pages are public webpages that are hosted and published via Github. They allow you to create a website simply by pushing you code to Github.

Github Pages is a hosting service for ==static webpages==, so it does not support server-side code.

- User site
  - `username.github.io`
- Project site
  - `username.github.io/repo-name`



```sh
$ git switch -c gh-pages

$ git touch index.html
$ git touch app.css
$ git touch app.js

$ git add .
$ git commit -m "Add github pages"
$ git push origin gh-pages

## Now you can find it in JoshTWang.github.io/CSEmpire
```
