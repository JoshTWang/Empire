# Git diff

We can use `git diff` command to view changes between commits, branches, files, working directory, and more!

We often use `git diff` alongside commands like `git status` and `git log` to get a better picture if a repository and how it has changed over time.



### Comparing changes between last commit, working directory, and staging area

---

#### `git diff`

Without additional options, `git diff` lists all the changes in our working directory that are NOT staged for the next commt.

###### Compared Files

```shell
diff --git a/rainbow.txt b/rainbow.txt
```

- For each comparison, Git explains which files it is comparing. Usually this is two versions of the same file.

- Git also declares one file as 'a' and the other as 'b'

###### File Metadata

```
index 0b75516..5ac6fae 100644
```

- The first two numbers are the hashes of the two files being compared.
- The last number is an internal file mode identifier.

###### Markers

```shell
--- a/rainbow.txt
+++ b/rainbow.txt
```

- File a and file b are each assigned a symbol.
  - File a gets a minus sign(-)
  - File b gets a plus sign(+)

###### Chunks

```shell
@@ -3,4 +3,5 @@ orange
 yellow
 green
 blue
-purple
\ No newline at end of file
+indigo
+violet
\ No newline at end of file
```

- A diff only shows portions or "chunks" that were modified.
- A chunk also includes some unchanged lines before and after a change to procide some content

Chunk Header

- Each chunk starts with a chunk header, found between @@ and @@
- Form file a, 4 lines are extracted starting from line 3
- From file b, 5 lines are extracted starting from line 3

Changes

- Every line that changeed between the two files marked with either + or - symbol.
  - lines that begin with - come from file a
  - lines that begin with + come from file b



#### `git diff HEAD`

- lists all changes in the working tree since your last commit



#### `git diff --staged`

#### `git diff --cached`

- list the changes between the staging area and our last commit



> Last Commit ----- Modified -----(add)----> Staged ---(commit)---> Committed
>
> `git diff`: from last commit to modified
>
> `git diff HEAD`: from last commit to modified + from last commit to staging area (already added)
>
> `git diff --staged`: from last commit to staging area



#### Difffing Specific Files

```shell
git diff [filename]
git diff HEAD [filename]
git diff --staged [filename]
```
