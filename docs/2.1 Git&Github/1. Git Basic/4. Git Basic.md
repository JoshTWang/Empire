# Git basics

#### Repository

A Git "Repo" is a workspace which tracks and manages files within a folder.



#### `git status`

Give information on the current status of a git repository and its contents.

```shell
$ git status
fatal: not a git repository (or any of the parent directories): .git

$ git init
Initialized empty Git repository in /Users/morningstar/Git/Codes/Basics/Novel/.git/

$ git status
On branch main

No commits yet

nothing to commit (create/copy files and use "git add" to track)
```



#### `git init`

To create a new git repository.

- Do once per project
- Initialize the repo in the top-level folder

This command creates an empty Git repository - basically a `.git` directory with subdirectories for `objects`, `refs/heads`, `refs/tags`, and template files. An initial branch without any commits will be created (see the `--initial-branch` option below for its name).

```shell
$ git init
Initialized empty Git repository in /Users/morningstar/Git/Codes/Basics/Novel/.git/
```



#### .git Folder

```shell
$ cd .git
$ ls
HEAD		config		description	hooks		info		objects		refs
```



#### A common mistake

- Git tracks a directory and all nested subdirectories
- **Do not init a repo inside of a repo**
  - Before running `git init`, use `git status` to verify that you are not currently inside a repo
- To delete a repo, locate the associated $.git$ directory and delete it



#### Git Workflow

1. Work On Stuff -- CRUD files
2. Add Changes  -- Group specific changes together
3. Commit -- Commit everything that was added



#### `git add`

 Add file contents to the index

Staging area

`git add filename/filenames/.`

```shell
$ git status
On branch main

No commits yet

Untracked files:
  (use "git add <file>..." to include in what will be committed)
        characters.txt
        outline.txt

nothing added to commit but untracked files present (use "git add" to track)

$ git add characters.txt outline.txt

$ git status
On branch main

No commits yet

Changes to be committed:
  (use "git rm --cached <file>..." to unstage)
        new file:   characters.txt
        new file:   outline.txt
```



#### `git commit`

#### `git commit -m "some message"`

`git commit` + default editor



#### `git commit -a -m "message"` 

-- add + commit

(Tell the command to automatically stage files that have been modified and deleted, but new files you have not told Git about are not affected.)



Record changes to the repository

```shell
$ git commit -m 'start our novel on outline and characters'
[main (root-commit) c8ba754] start our novel on outline and characters
 2 files changed, 4 insertions(+)
 create mode 100644 characters.txt
 create mode 100644 outline.txt
$ git status
On branch main
nothing to commit, working tree clean
```
