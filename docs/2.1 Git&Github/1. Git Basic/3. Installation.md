### Configuring name and email

```shell
$ git log
commit eb1419ea043ff9c786d525662e19b0a4f856319b (HEAD -> main, origin/main, origin/HEAD)
Author: leoever3 <leotwang@bu.edu>
Date:   Sun Sep 11 19:51:32 2022 -0400

    ALL DONE!!!
```



```shell
$ git config user.name
leoever3

$ git config --global user.name "Tianxiong Wang"

$ git config user.name
Tianxiong Wang

$ git config user.email
leotwang@bu.edu
```
