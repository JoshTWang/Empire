# Git More

#### Git Commit Guidelines

- Commit early and often
- Make commits atomic
- Write meaningful but concise commit messages



#### Writing Commit Messages

- Present tense
- Imperative mode



#### Configuring Default Editor

1. `$ git config --global core.editor "code --wait"`
2. Shell command: install `code` command in path



#### Amending Commits

- Redo the previous commit (one commit ago)

```shell
git commit -m 'some changes'
git add forgotten_file
git commit --amend
```



#### ==.github== to ignore files

- Secret, API keys, credentials
- OS files(.DS_Store)
- Log files
- Dependencies & packages

Create a file called $.gitignore$ in the root of a repository

```text
.DS_tore
secret.txt
node_modules/
*.log
```
