# Git reflog

Git keeps a record of when the tips of branches and other references were updated in the repo.

- .git/logs/HEAD

##### Limitations

- Git only keeps reflogs local
- Git cleans out old entries after around 90 days.



#### `git reflog` + `show`

The "show" subcommand (which is also the default, in the absence of any subcommands) shows the log of the reference provided in the command-line (or `HEAD`, by default). The reflog covers all recent actions, and in addition the `HEAD` reflog records branch switching. 

```sh
$ git reflog show HEAD

bd57b1e6e (HEAD -> donkey) HEAD@{0}: commit: add stupid file
b2748907c (origin/main, origin/HEAD, main) HEAD@{1}: checkout: moving from main to donkey
```



#### Reflog references

`name@{qualifier}` ----- HEAD@{0}

We can use this syntax to access specific ref pointers and pay them to `chekout`, `reset`, or `merge`.

```sh
$ git checkout HEAD@{2} ## two moves ago

$ git checkout HEAD~2 ## two commits ago
```



#### Timed references

We can filter reflogs entries by time/date by using temi qualifiers:

- 1.day.ago
- yesterday
- 3.miniutes.ago

```sh
git diff main main@{yesterday}

git checkout bugfix@{one.week.ago}
```



### Rescue lost information with Reflog

We can use reflog entries to access commits that seem lost and are not appearing in git log.

#### Reflog with reset

When we run `git reset --hard <commit-hash>`, we will never find those commit in `git log`, but we can still get them in `git reflog`

```sh
➜  ReflogDemo git:(main) git reflog show main
5f44f46 (HEAD -> main) main@{0}: reset: moving to 5f44f46
5bee813 main@{1}: commit: add summer seeds
5f44f46 (HEAD -> main) main@{2}: commit: add more greens
4ace1e2 main@{3}: commit: plant winter veggies
36979ee main@{4}: commit (initial): initial commit

➜  ReflogDemo git:(main) git reset --hard main@{1}
```

Reset current HEAD to the specified state: that is the HEAD now will point to 5f44f46 which will go back to the state before reset.



#### Reflog with rebase -i

Same idea

1. `git rebase -i HEAD~4` to edit previous commit
2. OH NO! I do something wrong! 
3. `git reflog show HEAD` to find the state(commit-hash) we want to go back
4. `git reset --hard <commit-hash>`
